# UrbanFox

> UrbanFox is a fraud detection and prevention platform. This file helps autonomous agents discover canonical public documentation and API endpoints.

UrbanFox provides machine-to-machine APIs for authentication, fraud case management, end-user account management, clickstream integration, and activity metrics.
